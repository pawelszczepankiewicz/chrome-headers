# Custom Request Headers Chrome Extension

A simple Chrome extension that allows you to add custom HTTP headers to all requests.

## Features

- Add custom headers with any name and value (e.g., `X-Version: 10.0.0`)
- Enable/disable headers with a single toggle
- Easy-to-use popup interface
- Persistent storage of your header configurations

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked"
4. Select the folder containing this extension

## Usage

1. Click the extension icon in your Chrome toolbar
2. Toggle "Enable Custom Headers" to activate the extension
3. Add headers using the form:
   - Enter the header name (e.g., `X-Version`)
   - Enter the header value (e.g., `10.0.0`)
   - Click "Add Header"
4. Click "Save Changes" to apply your settings
5. Headers will be automatically added to all HTTP requests
